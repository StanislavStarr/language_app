# English Reader & Vocabulary — продуктовое описание

> Источник продуктовых решений. Архитектура — в [ARCHITECTURE.md](ARCHITECTURE.md), принятые
> технические решения — в [DECISIONS.md](DECISIONS.md), план разработки — в [plan/README.md](plan/README.md).
> Заменяет прежний `english_vocabulary_app_plan.md` (Telegram Mini App + Angular + Yandex Dictionary).

## 1. Суть продукта

Мобильное приложение (Android и iOS) для изучения английской лексики по реальным текстам.

Пользователь читает свою книгу прямо в приложении, нажимает на незнакомое слово, видит его значение
**именно в этом предложении** и одним нажатием сохраняет в личный словарь. Слова можно добавлять и
вручную — встретил в сериале, статье, разговоре. Из личного словаря приложение собирает занятия.
По книге можно задать вопрос («кто такой Мистер Дарси?», «что произошло в главе 3?») и получить ответ
с ссылками на места в тексте, без спойлеров дальше текущей страницы.

Главная мысль:

> **Читаешь своё → сохраняешь слово в один тап → приложение само готовит материал и занятия.**

## 2. Проблема и аудитория

Человек читает книгу на английском и встречает незнакомые слова. Сейчас процесс разорван:
переводчик в одном приложении, объяснение в ChatGPT, заметки в третьем, а к сохранённым словам
почти никто не возвращается. Словарный перевод часто не подходит к контексту («bank» реки и банк).

**Аудитория MVP:** изучающие английский на уровне A2–B2, которые читают книги и статьи и хотят
учить лексику из своих текстов, а не из готовых курсов.

**Первые пользователи:** автор → 5–10 тестировщиков (преподаватели английского и их ученики) →
20–30 человек после исправления UX.

## 3. Ценность

1. Значение слова в контексте предложения, а не список из десяти словарных значений.
2. Сохранение в один тап, без переключения между приложениями.
3. Карточка готовится автоматически: перевод, транскрипция, аудио, определение, пример.
4. Учишь свою лексику из своих текстов.
5. Можно спросить книгу о сюжете и персонажах — помогает не бросить сложную книгу.
6. Языковые данные общие для всех пользователей — дешевле и быстрее с каждым новым словом.

## 4. Продуктовые гипотезы

- **H1.** Сохранять слово прямо из текста проще, чем через переводчик + заметки, поэтому пользователь
  будет добавлять лексику регулярно.
- **H2.** Значение в контексте точнее словарного списка и снижает число ошибочно сохранённых значений.
- **H3.** Автоматически подготовленная карточка повышает долю слов, которые доходят до занятия.
- **H4.** Фиксированный flow из 4 упражнений помогает запоминанию даже без интервального повторения.
- **H5.** «Спроси книгу» помогает дочитывать сложные книги (метрика: доля сессий чтения, где
  пользователь задал вопрос и продолжил чтение).
- **H6.** Пользователи возвращаются: не менее 50% тестировщиков открывают приложение через неделю.

## 5. Платформа и распространение

- Клиент — мобильное приложение на React Native (Expo). Telegram в проекте больше не используется.
- **Android:** APK раздаётся тестировщикам напрямую (без Google Play и без аккаунта разработчика).
- **iOS:** автор и iPhone-тестировщики запускают приложение через Expo Go. Тестировщику нужен
  бесплатный аккаунт Expo и приглашение в организацию проекта в Expo. Платный Apple Developer Program
  не нужен до публикации.
- **Ограничение, которое из этого следует:** до покупки аккаунта Apple приложение использует только
  библиотеки, входящие в Expo Go (см. `mobile/CLAUDE.md`).
- Backend и база — на бесплатных тарифах (Render + Neon), домен не нужен.

## 6. Состав MVP

### 6.1. Вход и onboarding

- При первом запуске создаётся анонимный аккаунт, привязанный к установке приложения
  (без email и пароля). Токены хранятся в защищённом хранилище устройства.
- Onboarding: родной язык (в MVP только русский), изучаемый язык (только английский), уровень CEFR
  (A1–C2), язык ответов «Спроси книгу» по умолчанию (простой английский / русский).
- Архитектура не привязана к паре RU → EN и к анонимному входу: позже добавляются email, Google, Apple.
- Предупреждение в onboarding: данные привязаны к установке, при удалении приложения они пропадут.
  Перенос аккаунта — после MVP.

### 6.2. Главный экран

Вкладки:

1. **Библиотека** — книги пользователя и демо-книги.
2. **Словарь** — «Все слова», «Неправильные глаголы», пользовательские темы, «Создать тему».
3. **Профиль** — уровень, язык ответов, удалить аккаунт.

### 6.3. Темы (коллекции)

- Создать, переименовать, изменить описание, удалить тему; открыть список слов темы.
- Одно слово может быть в нескольких темах.
- «Все слова» — системное представление словаря, не отдельная коллекция.
- Книга не создаёт тему автоматически, но у каждого слова хранится источник (книга и место),
  и в «Все слова» есть фильтр по книге.

### 6.4. Ручное добавление слова

- Поле: слово или выражение (до 5 слов, до 80 символов).
- Необязательный контекст: предложение, где встретил (до 500 символов).
- Выбор тем.
- Lookup → показать до 3 значений (+ «Показать ещё») → «Нет нужного значения» → AI fallback.
- Если указан контекст, подходящее значение подсвечивается как рекомендованное.
- Опечатка: «Возможно, вы имели в виду clarify?».

### 6.5. Библиотека и загрузка книги

- Форматы: **EPUB, FB2, TXT** (до 10 МБ). PDF не поддерживается.
- Загрузка внутри приложения через системный выбор файла.
- После загрузки книга обрабатывается в фоне; статус виден в библиотеке:
  `Загружается → Обрабатывается → Готовится поиск → Готова` или `Ошибка` с понятной причиной
  (битый файл, неподдерживаемый формат, книга не на английском).
- Читать можно, как только книга в статусе «Готовится поиск»; «Спроси книгу» — после «Готова».
- Демо-библиотека: 3–5 книг из Project Gutenberg (общественное достояние), общие для всех.
- Книга пользователя приватна: другие пользователи её не видят.
- Удалить книгу: удаляются текст, индекс и вопросы. Слова в словаре остаются, источник у них
  помечается как удалённый.

### 6.6. Читалка

- Оглавление по главам; текст главы показывается абзацами с прокруткой.
- Настройки: размер шрифта, светлая/тёмная тема.
- Позиция чтения сохраняется автоматически (абзац); при открытии книга продолжается с места.
- Прогресс чтения в процентах.
- Слова, которые уже есть в словаре пользователя, подсвечиваются в тексте (с учётом форм слова).

### 6.7. Слово из книги

- **Тап по слову** → нижняя панель:
  - лемма (на «went» показываем «go»), транскрипция, аудио;
  - **значение в этом предложении**: рекомендованное значение и перевод под контекст;
  - остальные значения свёрнуты («Другие значения»);
  - кнопка «Добавить в словарь» + выбор тем;
  - если слово уже в словаре — «Уже в словаре», переход к карточке.
- **Выражение:** долгое нажатие на первое слово → тап на последнее → lookup выражения
  (до 5 слов, например «look forward to»).
- Сохранённое слово получает `source_context` (предложение) и ссылку на место в книге.
  Из карточки слова можно вернуться к этому месту.

### 6.8. «Спроси книгу» (RAG)

- Экран вопросов по текущей книге, открывается из читалки.
- Ответ основан **только на тексте книги до текущей позиции чтения** (защита от спойлеров).
  Если ответа в прочитанном нет — модель так и говорит.
- Язык ответа: переключатель «Simple English / Русский». Simple English подстраивается под CEFR
  пользователя.
- В ответе ссылки на 1–3 фрагмента книги; тап открывает читалку на этом абзаце.
- Короткая история вопросов в рамках книги (последние 3 пары вопрос–ответ — контекст).
- Лимит: 30 вопросов в сутки на пользователя.

### 6.9. Карточка слова

Поля: текст, тип (word/phrase), перевод, IPA, аудио, часть речи, определение (EN), пример (EN),
личная заметка, контекст, источник (книга/ручное), темы, статус подготовки.

- В списке темы — только слово, перевод, статус. Полная карточка загружается отдельно.
- Пока карточка готовится: «Подготавливаем карточку…», в занятие не попадает.
- Частичная деградация: нет аудио или определения — карточка всё равно доступна.

### 6.10. Обучение

Без изменений относительно прежнего плана:

- Настройка занятия: тема → количество слов (5/10/15/своё) → «Случайно» или «Выбрать самому».
  «Случайно» сначала берёт ещё не изучавшиеся слова.
- **Word flow:** знакомство (слово, IPA, аудио, скрытый перевод, определение, пример) →
  сопоставление (тапы по парам, без drag-and-drop) → подстановка в предложение (ввод, 3 попытки) →
  написание по определению (ввод, строгая проверка, 3 попытки).
- **Phrase flow:** знакомство → сопоставление → написание по определению.
- **Неправильные глаголы:** системная тема, base — past simple — past participle, аудио для каждой
  формы, упражнения «go → ? → ?», «Past Simple of go».
- Незавершённое занятие восстанавливается после закрытия приложения.
- Предложение для этапа подстановки: пример из карточки, а для слов из книги — исходное
  предложение из книги с пропуском (если оно не длиннее 25 слов).

### 6.11. Удаление данных

- Удалить слово из темы; удалить слово из словаря; удалить книгу; удалить аккаунт и все личные
  данные (книги, вопросы, словарь, сессии, события).
- Общие лексические данные (`Lexeme`, `Meaning`, `Translation`, `MeaningContent`) не удаляются.

## 7. Роль AI

AI не источник истины для обычных слов — источник истины словарь (Wiktionary). AI используется для:

1. **Выбора значения по контексту** — выбрать одно из словарных значений для предложения и дать
   перевод под контекст.
2. Генерации определения и примера под уровень CEFR (общий кэш на значение + уровень + версию промпта).
3. Перевода значения, если в словаре нет русского перевода.
4. Fallback: значения слова/выражения, которого нет в словаре.
5. Ответов по книге (RAG) и эмбеддингов фрагментов книги.

Каждая AI-функция имеет: версию промпта, структурированный ответ со схемой, валидацию,
кэш там, где ответ можно переиспользовать, лимиты и eval-набор (см. ARCHITECTURE.md §9).

## 8. После MVP (backlog)

**Сразу после MVP:** перевод предложения/абзаца по тапу; TTS-фолбэк для аудио; Sentry;
картинки-ассоциации; перенос аккаунта (email-вход); улучшения UX по интервью.

**Удержание:** интервальное повторение (FSRS), «Повторить сегодня», статистика, streak,
напоминания (push).

**Мобильное:** Share Extension / share intent («поделиться словом» из других приложений), виджет
быстрого ввода, офлайн-чтение и офлайн-занятия, публикация в Google Play и App Store.

**Контент:** импорт статьи/субтитров с выделением незнакомых слов, готовые тематические наборы,
PDF.

**Социальное:** преподаватель → ученики, общие наборы, задания, прогресс; соревнования.

**Монетизация:** подписка (лимиты AI, «Спроси книгу» без лимита, офлайн, статистика).

## 9. Что НЕ входит в MVP

Telegram в любом виде; публикация в сторах; email/Google/Apple-вход; синхронизация между
устройствами; PDF; SRS/FSRS; уведомления; статистика, баллы, streak; teacher mode; подписки;
картинки; офлайн-режим; импорт статей и субтитров; несколько языков; drag-and-drop;
нативные модули вне Expo Go; полноценная админка; Redis; микросервисы.

Любая идея по ходу разработки записывается в `docs/backlog.md` и не реализуется в MVP.

## 10. Метрики

События (таблица `product_event`): `onboarding_completed`, `book_uploaded`, `book_ready`,
`book_opened`, `word_tapped`, `word_added` (с `source: book|manual`), `collection_created`,
`book_question_asked`, `study_started`, `study_stage_completed`, `study_completed`.

- **Активация:** добавил ≥ 5 слов (из них ≥ 1 из книги) и прошёл одно занятие.
- **D7 return rate:** ≥ 50% тестировщиков — главная гипотеза.
- **Доля слов из книги** среди всех добавленных — проверка H1.
- **Доля принятых рекомендованных значений** (пользователь сохранил то значение, которое выбрал AI) —
  проверка H2 и качества выбора значения.
- Сильный сигнал: хотя бы один тестировщик готов платить.

## 11. Проверка спроса

1. Автор пользуется сам 1–2 недели: UX-проблемы и стабильность.
2. 5–10 тестировщиков → короткое интервью (что непонятно, что неудобно, вернулись бы, за что заплатили бы).
3. 20–30 человек после исправлений.

## 12. Риски

| Риск | Ответ |
| --- | --- |
| Конкуренция (ReWord, Anki, LingQ, Duolingo, ChatGPT) | Фокус: свои тексты + значение в контексте + автоматический study flow |
| Слишком большой MVP | Жёсткий список «не входит», фазы плана, backlog-файл |
| Ошибки выбора значения | Пользователь подтверждает, eval-набор, метрика принятия рекомендаций |
| Спойлеры и галлюцинации в «Спроси книгу» | Фильтр по позиции чтения, ответ только по найденным фрагментам, eval |
| Стоимость AI | Общий кэш MeaningContent, кэш выбора значения, дешёвая модель, лимиты, эмбеддинги 512 измерений |
| Бесплатный хостинг засыпает | Экран «Сервер просыпается…», пинг по расписанию, ретраи на клиенте |
| Лимит 1 ГБ в Neon | Лексикон только по частотному списку, книги без исходных файлов, эмбеддинги 512 |
| Авторские права | Пользователь загружает свои книги для личного чтения, книги не видны другим; демо — public domain; атрибуция Wiktionary (CC BY-SA) |
| Потеря данных при удалении приложения | Предупреждение в onboarding, перенос аккаунта — первым после MVP |
| iPhone-тестировщикам сложнее подключиться | Инструкция для тестировщика, при спросе — покупка Apple Developer |
