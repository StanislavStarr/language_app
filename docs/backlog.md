# Backlog (после MVP)

Идеи, которые появились по ходу разработки MVP. Сюда записываем, **не реализуем** до конца MVP.
Плановый post-MVP список — в [PRODUCT.md §8](PRODUCT.md).

Формат: `- [дата] идея — откуда взялась (задача/интервью) — ценность`

## Идеи


- `WWW-Authenticate: Bearer` в ответах 401 (RFC 6750).

- Загрузка книг (T3.x): `createAuthMiddleware` клонирует каждый запрос для повтора после 401, для больших multipart-тел это удваивает буфер; исключить эндпоинт загрузки или повторять вручную.
- `unwrap` рассчитан на ответы с телом; для 204 (`DELETE`) добавить отдельный вариант, когда появится первый такой эндпоинт на клиенте.

- Адрес API на телефоне: порт и IP в `mobile/.env` легко перепутать; показывать `env.apiUrl` на экране ошибки входа в режиме разработки.

- «Удалить аккаунт» в профиле (PRODUCT §6.2, §6.11): нужен `DELETE /users/me` на backend (каскадное удаление) и подтверждение на клиенте.
- Автотест навигатора с `Stack.Protected` (`expo-router/testing-library`): переход онбординг → вкладки после `complete_onboarding`.
- Общие тестовые хелперы mobile (`jsonResponse`, `renderWithProviders`, `USER`): дублируются в нескольких тестах страниц и шлюзов.
- Порог `pg_trgm` 0,45 для подсказок об опечатках не ловит перестановки в коротких словах (`houze` → `house` 0,33, `recieve` → `receive` 0,33, `wotter` → `water` 0,30), но ловит `beautifull` (0,75) и `hous` (0,57). При реализации lookup оценить порог ≈ 0,3 с ранжированием по частоте или расстояние Левенштейна (`fuzzystrmatch`).
- Импорт лексикона: удалять устаревшие значения, формы и переводы источника `wiktionary`, на которые нет ссылок из `user_vocabulary_item` и `sense_selection` (сейчас импорт только добавляет, ADR-014).
- Импорт лексикона: строить черновики лениво по батчам, чтобы не держать все статьи 55 тысяч лексем в памяти (сейчас достаточно, прогон занимает около 3 минут).


- T2.7: валидация AI-созданных лексем (минимальная уверенность/фильтр содержимого) перед записью в общий `lexeme`; возврат единицы `ai_lookup` при сбое AI.

- T2.8: `MeaningCatalog.details` отдаёт ORM-объекты лексикона в `vocabulary` — заменить DTO; `MAX_COLLECTIONS_PER_USER` проверяется не атомарно (гонка допустима для MVP); `forms` на больших словарях — подумать о кэше.

- T2.9: повторный запуск зависших `pending`-карточек (очередь была недоступна); сменa CEFR-уровня пользователя не перегенерирует контент; поддержка отдельного процесса воркера (точка входа с runtime); тест lifespan на установку runtime; общий вызов AI с флагом вместо двух копий цикла (`call_unless_unavailable`).
