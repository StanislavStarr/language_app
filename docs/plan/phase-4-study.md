# Фаза 4 — Обучение (~24 ч)

**Результат:** пользователь проходит занятие по теме (4 этапа для слов, 3 для фраз) и по
неправильным глаголам; незавершённое занятие восстанавливается.

---

## Backend

### T4.1 — Учебные сессии                                         ~6 ч   [ ]

**Контекст:** ARCHITECTURE.md §5.5, §6.7; PRODUCT.md §6.10.
**Сделать:** модуль `study`: модели + миграция (частичный unique на активную сессию);
сервис отбора слов (новые первыми, затем случайные изученные; только готовые карточки с
определением; минимум 2 слова, иначе `not_enough_words`); `POST /study-sessions`
(`collection_id?`, `size`, `mode: random|manual`, `item_ids?`) — существующая активная сессия
помечается `abandoned`; `GET /study-sessions/active`, `GET /study-sessions/{id}` — полезная
нагрузка с данными упражнений: для этапа `sentence` сервер готовит предложение с пропуском
(исходное предложение из книги ≤ 25 слов, содержащее словоформу, иначе пример); варианты для
`matching` перемешаны детерминированно по id сессии; `PATCH …/progress` (Pydantic-схема
`stage_state`, текущий этап не может идти назад); `POST …/complete` (`study_count + 1`,
`last_studied_at`).
**Тесты:** отбор (новые первыми, исключение неготовых); подготовка предложения из книги и
фолбэк на пример; фразы без этапа `sentence`; повторное завершение — идемпотентно.

### T4.2 — Неправильные глаголы                                  ~3 ч   [ ]

**Сделать:** `backend/scripts/data/irregular_verbs.json` (~150 глаголов: base, past simple,
past participle, перевод); скрипт загрузки, связывающий с `lexeme` и берущий аудио форм из
лексикона; `GET /irregular-verbs`; сессии `kind = irregular_verbs`.
**Приёмка:** данные сверены с лексиконом: скрипт печатает глаголы, у которых формы не совпали
с Wiktionary, и они исправлены вручную.

## Mobile

### T4.3 — Машина состояний занятия                               ~5 ч   [ ]

**Контекст:** `mobile/CLAUDE.md` (чистая логика в `lib`).
**Сделать:** `entities/study-session/lib`: редьюсер `studySessionReducer(state, action)` —
этапы, порядок, попытки (3), выбранные пары в matching, переход к следующему слову/этапу,
пропуск этапа для фраз, восстановление из `stage_state`; `checkAnswer(expected, actual)` —
строгая проверка после нормализации (регистр, пробелы, типографские апострофы); сериализация
состояния в `stage_state`.
**Тесты:** исчерпывающие unit-тесты: каждый переход, 3 ошибки → показ ответа, фразы,
восстановление с середины этапа, matching (неверная пара, повторный выбор).

### T4.4 — Экраны занятия                                        ~6 ч   [ ]

**Сделать:** `pages/study-setup` (тема → размер → случайно/вручную со списком слов),
`pages/study-session` (контейнер: загрузка, синхронизация прогресса после каждого шага с
debounce, завершение), виджеты этапов `study-introduction`, `study-matching`, `study-sentence`,
`study-definition`, экран итога; аудио на этапе знакомства.
**Тесты:** каждый этап рендерится и отправляет действия в редьюсер.

### T4.5 — Занятие по неправильным глаголам                       ~2 ч   [ ]

**Сделать:** виджет упражнения «go → ? → ?» и вопросы «Past Simple of go»; страница темы
«Неправильные глаголы» (список с аудио форм).

### T4.6 — Продолжение занятия                                    ~2 ч   [ ]

**Сделать:** при входе на вкладку «Словарь» и в теме — плашка «Продолжить занятие?» для
активной сессии (`GET /study-sessions/active`); восстановление этапа и позиции.
**Приёмка:** закрыть приложение на этапе `sentence`, открыть — продолжить с того же слова.
