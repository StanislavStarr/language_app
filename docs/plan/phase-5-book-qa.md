# Фаза 5 — «Спроси книгу» (RAG) (~20 ч)

**Результат:** по прочитанной части книги можно задать вопрос и получить ответ со ссылками на
абзацы, на простом английском или русском, без спойлеров; качество измерено evals.

---

## Backend

### T5.1 — Чанки и индексация                                     ~4 ч   [ ]

**Контекст:** ARCHITECTURE.md §5.4 (`book_chunk`), §6.4 (`index_book`); DECISIONS ADR-007.
**Сделать:** модуль `book_qa`: модель `book_chunk` + миграция (`vector(512)`, generated
`tsvector('english', text)`, HNSW `vector_cosine_ops`, GIN, индекс `(book_id, end_position)`);
`integrations/embeddings/` (Protocol, OpenAI с `dimensions=512`, батчи по 64, ретраи;
`FakeEmbeddingProvider` с детерминированными векторами); чанкер — чистая функция по абзацам
(200–400 токенов, перекрытие 1 абзац, не пересекает главы); настоящий `index_book`;
`scripts/reindex_books.py` для уже загруженных книг и демо-книг.
**Тесты:** чанкер (длинный абзац > 400 токенов становится отдельным чанком; границы глав;
перекрытие); индексация с fake-эмбеддингами.

### T5.2 — Гибридный поиск                                       ~4 ч   [ ]

**Контекст:** ARCHITECTURE.md §6.6 шаг 4.
**Сделать:** репозиторий `search_chunks(book_id, max_position, query_embedding, query_text, k)`:
vector top-20 и FTS top-20 с фильтром `end_position <= max_position`, слияние RRF (k = 60);
параметры — в настройках.
**Тесты:** фильтр позиции (чанк после позиции никогда не возвращается, даже при идеальном
совпадении); RRF-слияние; запрос без FTS-совпадений.

### T5.3 — Ответы на вопросы                                      ~4 ч   [ ]

**Контекст:** ARCHITECTURE.md §6.6; PRODUCT.md §6.8; skill `llm-feature`.
**Сделать:** AI-фича `answer_book_question` (промпт с версией, схема `{answer, found_in_text,
cited_chunk_ids}`, язык и CEFR, последние 3 пары вопрос–ответ); сервис: лимит, позиция с
сервера, поиск, вызов, проверка ссылок, сохранение `book_question`; `POST /books/{id}/questions`,
`GET /books/{id}/questions`; книга не `ready` → `book_not_indexed`.
**Тесты:** ссылки вне переданных чанков отбрасываются; `found_in_text = true` без ссылок →
`false`; лимит; история.

### T5.4 — Eval «Спроси книгу»                                    ~4 ч   [ ]

**Контекст:** ARCHITECTURE.md §9; subagent `eval-analyst`.
**Сделать:** `book_qa.jsonl` — 40 вопросов по двум демо-книгам: `reading_position`, эталонные
абзацы, `answerable`, 8+ «ловушек спойлера» (ответ есть только дальше позиции), 6+ вопросов на
русском; метрики: recall@6, **спойлерные утечки (должно быть 0)**, точность для вопросов без
ответа, faithfulness (judge); базовый отчёт → подбор параметров (размер чанка, k, порог) →
финальный отчёт.
**Приёмка:** метрики не ниже целевых в ARCHITECTURE.md §9; отчёты «до/после» в `docs/evals/`.

## Mobile

### T5.5 — Экран вопросов к книге                                 ~4 ч   [ ]

**Сделать:** `features/ask-book` + `pages/book-qa`: история вопросов, поле ввода (≤ 300),
переключатель «Simple English / Русский» (по умолчанию из профиля), индикатор ожидания, ответ
со ссылками-чипами (глава + фрагмент) → читалка на абзаце; состояния: книга ещё индексируется,
лимит, «В прочитанной части ответа нет»; вход из читалки.
**Тесты:** рендер ответа со ссылками; переход по ссылке передаёт `paragraph_position`.
