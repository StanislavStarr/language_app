# Фаза 3 — Читалка (~32 ч)

**Результат:** пользователь загружает свою книгу, читает её, нажимает на слово или выделяет
выражение, видит значение в контексте и сохраняет его; сохранённые слова подсвечиваются в тексте.

---

## Backend

### T3.1 — Книги: модели и загрузка                              ~4 ч   [ ]

**Контекст:** ARCHITECTURE.md §5.4, §6.4; PRODUCT.md §6.5.
**Сделать:** модуль `books`: модели `book`, `book_upload`, `book_chapter`, `book_paragraph`,
`reading_progress` + миграция; `POST /books` (multipart): размер ≤ 10 МБ, расширение и сигнатура
(EPUB — zip с `mimetype`, FB2 — XML с `FictionBook`, TXT — декодируемый текст), sha256-дедупликация,
лимиты (`book_upload` в сутки, 20 книг всего); `GET /books` (свои + демо, с прогрессом чтения),
`GET /books/{id}`, `DELETE /books/{id}` (каскад; у слов из книги `book_id`/`paragraph_id` → NULL).
**Тесты:** каждая ветка валидации; дубликат; чужая книга → 404; демо-книгу удалить нельзя (403).

### T3.2 — Парсеры EPUB, FB2, TXT                                ~6 ч   [ ]

**Контекст:** ARCHITECTURE.md §6.4; `backend/CLAUDE.md` (безопасность).
**Сделать:** `modules/books/parsers/`: общий DTO `ParsedBook(title, author, chapters[paragraphs])`;
`EpubParser` (spine, оглавление, XHTML → блоки текста, лимит распаковки), `Fb2Parser`, `TxtParser`
(кодировка, эвристика глав); нормализация текста; проверка языка; `sentence_spans`.
Парсеры — чистые функции от байтов, без БД.
**Тесты:** фикстуры в `tests/fixtures/books/`: маленькие EPUB/FB2/TXT, собранные в тестах
программно, + одна реальная небольшая книга Project Gutenberg; битый zip; zip bomb (маленький
архив с огромным содержимым); XML с внешней сущностью (XXE) → отказ; не английский текст;
пустая книга.

### T3.3 — Обработка книги в фоне                                ~3 ч   [ ]

**Сделать:** задачи `parse_book` и `index_book` (в этой фазе `index_book` только ставит статус
`ready`; индексация — в T5.1); статусы и `error_code`; удаление `book_upload`; батчевые вставки.
**Приёмка:** реальная EPUB-книга на 100k слов обрабатывается < 1 мин локально.
**Тесты:** успешный путь; ошибка парсинга → `failed` с кодом; повторный запуск после падения.

### T3.4 — API читалки и демо-книги                              ~3 ч   [ ]

**Сделать:** `GET /books/{id}/toc`, `GET /books/{id}/chapters/{chapter_index}`,
`PUT /books/{id}/progress`; читать можно со статуса `indexing`; скрипт
`scripts/seed_demo_books.py`: 3–5 книг из Project Gutenberg (EPUB, общественное достояние;
шапка и лицензия Gutenberg удаляются, бренд не используется), владелец `NULL`, идемпотентно.
**Тесты:** доступ к главе до готовности → `book_not_ready`; прогресс за пределами книги → 422.

### T3.5 — Lookup и добавление слова из книги                     ~3 ч   [ ]

**Контекст:** ARCHITECTURE.md §6.2 (вариант `book`), §6.3.
**Сделать:** вариант `source: "book"` в `POST /lexemes/lookup` и `POST /vocabulary`: проверка
доступа к книге, извлечение предложения по `sentence_spans`, лемматизация в контексте; в словарь
сохраняются `book_id`, `paragraph_id`, `source_context`, `context_translation`; `GET /vocabulary?book_id=`.
**Тесты:** span вне абзаца → 422; слово в середине длинного предложения; фраза через границу
предложения → 422 `phrase_crosses_sentence`.

### T3.6 — Eval выбора значения на книгах                        ~2 ч   [ ]

**Сделать:** расширить `sense_selection.jsonl` до 100 кейсов из демо-книг; прогон; если
accuracy < 0.85 — итерации промпта (новая версия) с отчётами «до/после».
**Skills:** `llm-feature`; subagent `eval-analyst`.

### T3.8 — Экран чтения                                          ~6 ч   [ ]

**Контекст:** ARCHITECTURE.md §6.5; PRODUCT.md §6.6.
**Сделать:**
- `entities/book/lib/tokenize-paragraph.ts` — чистая функция: токены `{text, kind: word|punct|space, charStart, charEnd}`
  (апострофы, дефисы, числа, кавычки);
- `widgets/reader-view`: `FlashList` абзацев главы; абзац — `AppText` с вложенными `Text`
  для слов (мемоизация по `paragraph.id` + набору подсвеченных форм); переходы между главами;
  оглавление в bottom sheet;
- `features/reader-settings`: размер шрифта, тема; хранение в Zustand + AsyncStorage;
- сохранение позиции (первый видимый абзац, debounce 2 с) и восстановление при открытии;
- подсветка: `GET /vocabulary/forms` → `Set`, сравнение по нижнему регистру.
**Приёмка:** глава ~5000 слов прокручивается плавно на среднем Android-телефоне; позиция
восстанавливается после перезапуска.
**Тесты:** токенизатор (≥ 15 кейсов: «don't», «well-known», «—», числа, кавычки, многоточие);
вычисление подсветки.
